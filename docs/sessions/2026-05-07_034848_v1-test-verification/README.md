## Generated Code Execution (Test 5)

`fib.py` was generated by the FAST tier (CODER only, `qwen2.5-coder:7b`).
The file contains a markdown code fence wrapping the Python source plus prose
documentation after the closing fence. Execution extracts only the first code
block:

```python
import re, pathlib
code = pathlib.Path("fib.py").read_text()
m = re.search(r'```(?:python)?\n(.*?)```', code, re.DOTALL)
exec(compile(m.group(1), "fib.py", "exec"))
```

Both `fibonacci()` (recursive) and `fibonacci_iterative()` were defined and loaded
without error. This pattern — extract first fence block, compile, exec — is the
recommended approach for running LLM-generated code that may include markdown prose.

## Issues Found and Resolved

### Fence + prose in generated output (Test 5)

**Problem:** Generated `fib.py` contains markdown fences around the code block
PLUS additional `### Documentation` prose after the closing fence. Stripping fence
markers line-by-line leaves invalid Python syntax.

**Fix:** Extract content between the first fence pair using:
```python
re.search(r'```(?:python)?\n(.*?)```', code, re.DOTALL).group(1)
```

**Status:** Resolved for test purposes. The CLI's `--quiet` flag outputs raw code
only (no fences, no prose) — use `--quiet -o outfile.py` for files intended to be
executed directly.

## CLI Quick Reference

```bash
# Configure once
gryphgen config set-key gryphgen-test-tandem-2026
gryphgen config set-url https://api.grug.ai

# Generate code
gryphgen gen "write a fibonacci function" -l python           # auto-tier
gryphgen gen "fibonacci" --tier fast --quiet                  # fast, code only
gryphgen gen "Redis rate limiter" -l python -o limiter.py     # save to file
gryphgen gen "refactor auth" --files auth.py middleware.py    # STRONG (multi-file)
gryphgen gen "fibonacci" --json                               # machine-readable output

# Agent (multi-step with tool use)
gryphgen agent "write hello.py and show its contents"

# Search
gryphgen search "Redis"

# Status
gryphgen health
gryphgen models
```

Key flag notes:
- `--tier fast|standard|strong` — override automatic routing
- `--quiet` / `-q` — suppress footer (gen time, tier, model)
- `--json` — output full JSON response to stdout
- `--files f1.py f2.py` — attach context files (auto-escalates to STRONG)
- `-o outfile.py` — write code to file instead of stdout
